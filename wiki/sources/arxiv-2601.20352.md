# ContextWeaver: A Framework for Long-Horizon Memory in LLM Agents

Wu et al., January 2026.

ContextWeaver è un framework per la gestione della memoria in agenti LLM con orizzonte temporale lungo. Il sistema "intreccia" contesti passati e presenti in una rappresentazione coerente che supporta sia il reperimento di fatti specifici che il ragionamento su stati evolutivi. Si concentra sul problema di mantenere coerenza across sessioni multiple quando lo stato del mondo e le intenzioni dell'utente cambiano nel tempo.
