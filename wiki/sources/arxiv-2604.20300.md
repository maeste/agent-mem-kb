# FSFM: Biologically-Inspired Selective Forgetting Framework

**Autori:** Gu et al. (China Mobile) | **arXiv:** 2604.20300 | **Apr 2026**

## Summary

FSFM è un framework neuro-ispirato per selective forgetting in agenti LLM, basato su hippocampal memory indexing/consolidation theory e curva di dimenticazione di Ebbinghaus. Argomenta che in ambienti resource-constrained, un meccanismo di forgetting ben progettato è cruciale quanto la retention per:

1. Efficienza computazionale e storage via pruning intelligente
2. Qualità contenuto via aggiornamento dinamico di preferenze obsolete
3. Sicurezza via active forgetting di input malevoli e dati sensibili

Tassonomia dei meccanismi: passive decay-based, active deletion-based, safety-triggered, adaptive reinforcement-based.

## Key claims

- Miglioramenti: efficienza accesso +8.49%, signal-to-noise ratio +29.2%, eliminazione rischi sicurezza 100% [[wiki/pages/fsfm]]
- Ponte tra neuroscienza cognitiva e sistemi AI per la gestione della memoria agentica
