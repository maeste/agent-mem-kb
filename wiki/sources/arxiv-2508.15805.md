# Agent Skills: A Survey and Critical Analysis of the Emerging Skill Paradigm for LLM Agents

Ling et al., August 2025.

Prima survey comprehensiva sul paradigma delle Agent Skills, l'astrazione emersa come primitivo architetturale unificante per agenti LLM. Traccia l'evoluzione da prompt engineering (2022-23) a tool use (2023-24) a skill engineering (2025-present), dove una skill è un bundle di istruzioni, workflow, script eseguibili, documentazione e metadata. Analizza la specifica SKILL.md (progressive disclosure: metadata ~30 tokens sempre caricati, istruzioni on-demand, risorse dynamic loading) e la sua relazione con MCP (Model Context Protocol). Propone una tassonomia dei metodi di acquisizione skill: RL, esplorazione autonoma, sintesi composizionale, knowledge packaging human-authored. Valuta lo stack CUA (Computer-Use Agent) come dominio di deployment primario. Include la prima analisi consolidata sulla sicurezza delle skill con uno Skill Trust and Lifecycle Governance Framework che mappa provenienza attraverso gate di verifica a permessi di deployment graduati.
