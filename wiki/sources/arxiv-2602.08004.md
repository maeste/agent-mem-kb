# Agent Skills: A Data-Driven Analysis of Claude Skills for Extending LLM Functionality

**Autori:** George Ling, Shanshan Zhong, Richard Huang (Bosch Research, CMU)
**arXiv:** 2602.08004 | Febbraio 2026

## Riassunto

Analisi data-driven su larga scala di 40.285 skills pubblicamente listate da un marketplace principale di agent skills. Lo studio esamina tipologie disponibili, pattern di adozione utente e rischi di sicurezza.

Risultati chiave:
- La pubblicazione di skills avviene a burst che tracciano i cambiamenti nell'attenzione della community
- Il contenuto delle skills è altamente concentrato in workflow software engineering
- Information retrieval e content creation contano una quota significativa di adozione
- Squilibrio pronunciato supply-demand tra categorie
- La maggior parte delle skills rimane entro typical prompt budgets nonostante distribuzione heavy-tailed
- Forte omogeneità dell'ecosistema con ridondanza intent-level
- Rischi sicurezza non-triviali: skills che abilitano azioni state-changing o system-level

## Claim chiave

- L'ecosistema agent skills mostra forte concentrazione in software engineering con squilibrio supply-demand [[wiki/sources/arxiv-2602.08004.md]]
- L'omogeneità intent-level suggerisce redundanza significativa nel marketplace [[wiki/sources/arxiv-2602.08004.md]]
- Una frazione non trascurabile di skills presenta rischi di sicurezza (azioni system-level) [[wiki/sources/arxiv-2602.08004.md]]
