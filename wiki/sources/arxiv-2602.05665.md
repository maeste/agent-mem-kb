# Graph Memory for LLM Agents

**Autori:** Yang et al. | **arXiv:** 2602.05665 | **Feb 2026**

## Summary

Lavoro su memory systems basati su grafi per agenti LLM. Esplora come strutturare la memoria agentica come knowledge graph per enable retrieval e reasoning più efficaci in scenari long-horizon.

## Key claims

- I grafi forniscono struttura relazionale che supera il retrieval vettoriale flat per certi tipi di query [[wiki/pages/graph-memory]]
