# Agent Skills: A Data-Driven Analysis of Claude Skills

**George Ling, Shanshan Zhong, Richard Huang** (Bosch Research, CMU) — arXiv:2602.08004, Feb 2026

## Summary

Analisi data-driven su larga scala di **40.285 skills** pubblicamente listate da un major marketplace di agent skills. Lo studio esamina tipi disponibili, pattern di adozione e rischi associati all'ecosistema delle skills in rapida crescita.

Risultati chiave:
- La pubblicazione di skills avviene a scatti (bursts) che tracciano i cambiamenti nell'attenzione della community
- Il contenuto è fortemente concentrato in workflow software engineering; information retrieval e content creation hanno share significativo di adozione
- **Pronunciato squilibrio supply-demand** tra categorie
- La maggior parte delle skills rimane dentro tipici prompt budget nonostante distribuzione heavy-tailed della lunghezza
- **Forte omogeneità dell'ecosistema**: diffusa ridondanza a livello intent
- **Rischi safety non-triviali**: skills che abilitano azioni state-changing o system-level

Il paper offre uno snapshot quantitativo delle skills come infrastruttura layer emergente per gli agenti.

## Key claims
- L'ecosistema skills mostra omogeneità e ridondanza significativa ([§Abstract](raw/papers/arxiv-2602.08004.pdf))
- Esistono rischi safety concreti nelle skills community-contributed ([§5](raw/papers/arxiv-2602.08004.pdf))
- Lo squilibrio supply-demand è strutturale, non temporaneo ([§4](raw/papers/arxiv-2602.08004.pdf))
