# Agent Skills: A Data-Driven Analysis of Claude Skills

**George Ling et al.** (Bosch Research, CMU), arXiv:2602.08004, Feb 2026.

## Summary

Analisi data-driven su larga scala di **40.285 skill** pubblicate su un marketplace principale di agent skills. Studia tipologie disponibili, pattern di adozione utente e rischi di sicurezza. Rappresenta la prima analisi quantitativa dell'ecosistema agent skills come layer infrastrutturale emergente.

## Key Claims

- La pubblicazione di skills avviene a **burst** che tracciano gli spostamenti dell'attenzione della community [[wiki/sources/ling-2026-agent-skills-analysis]](raw/papers/arxiv-2602.08004.pdf).
- Il contenuto delle skills è **altamente concentrato in workflow software engineering**, mentre information retrieval e content creation rappresentano una quota significativa di adozione [[wiki/sources/ling-2026-agent-skills-analysis]](raw/papers/arxiv-2602.08004.pdf).
- Pronunciato **squilibrio supply-demand** tra categorie; forte omogeneità dell'ecosistema con ridondanza a livello intent [[wiki/sources/ling-2026-agent-skills-analysis]](raw/papers/arxiv-2602.08004.pdf).
- Rischi sicurezza non trascurabili: skills che abilitano azioni state-changing o system-level [[wiki/sources/ling-2026-agent-skills-analysis]](raw/papers/arxiv-2602.08004.pdf).
