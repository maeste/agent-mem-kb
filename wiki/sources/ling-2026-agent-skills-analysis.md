# Agent Skills: A Data-Driven Analysis of Claude Skills for Extending LLM Functionality

**Autori:** George Ling (Bosch), Shanshan Zhong (CMU), Richard Huang (Bosch) | **arXiv:** 2602.08004 | **Febbraio 2026**

## Sintesi

Analisi data-driven su **40.285 skills** pubblicate da un marketplace principale. Fornisce uno snapshot quantitativo delle agent skills come strato infrastrutturale emergente.

## Risultati chiave

- La pubblicazione di skills avviene a **burst** che tracciano i cambiamenti nell'attenzione della community
- Contenuto **altamente concentrato** in workflow di software engineering; information retrieval e content creation hanno share significativo di adozione
- **Pronunciato squilibrio supply-demand** tra categorie
- La maggior parte delle skills resta entro budget tipici nonostante distribuzione heavy-tailed della lunghezza
- **Forte omogeneita dell'ecosistema**: ridondanza intent-level diffusa
- **Rischi safety non banali**: skills che abilitano azioni state-changing o system-level
