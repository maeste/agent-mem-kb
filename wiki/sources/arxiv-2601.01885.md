# ALAS: Agent Long-term Memory with Abstraction and Least-to-Most Reasoning

Atreja et al., January 2026.

ALAS è un framework per la memoria a lungo termine di agenti LLM che combina astrazione gerarchica con ragionamento least-to-most. Il sistema organizza le memorie in livelli di astrazione crescente, permettendo all'agente di partire da rappresentazioni generali e scendere ai dettagli solo quando necessario. Questo approccio bilancia efficienza di reperimento con completezza informativa, evitando sia il sovraccarico di contesto che la perdita di dettagli rilevanti.
