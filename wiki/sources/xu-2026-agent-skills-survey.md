# Agent Skills for LLMs: Architecture, Acquisition, Security, and Path Forward

**Renjun Xu, Yang Yan** (Zhejiang University), arXiv:2602.12430, Feb 2026.

## Summary

Survey comprehensivo sul paradigma **agent skills**, il primo trattamento focalizzato su questo layer di astrazione. Organizza il campo lungo quattro assi: (1) fondazioni architetturali (SKILL.md, progressive disclosure, MCP); (2) acquisizione skills (RL con skill libraries, scoperta autonoma, sintesi composizionale); (3) deploy a scala (CUA stack, GUI grounding, benchmark OSWorld/SWE-bench); (4) sicurezza (26.1% delle skills community contengono vulnerabilità). Propone uno Skill Trust and Lifecycle Governance Framework a quattro tier.

## Key Claims

- Il **26.1%** delle skills contribute dalla community contengono vulnerabilità [[wiki/sources/xu-2026-agent-skills-survey]](raw/papers/arxiv-2602.12430.pdf).
- Skills e MCP definiscono uno stack agentic emergente in cui skills forniscono "cosa fare" e MCP fornisce "come connettersi" [[wiki/sources/xu-2026-agent-skills-survey]](raw/papers/arxiv-2602.12430.pdf).
- Sette open challenges identificati: portabilità cross-platform, permission models basati su capability, e altri [[wiki/sources/xu-2026-agent-skills-survey]](raw/papers/arxiv-2602.12430.pdf).
